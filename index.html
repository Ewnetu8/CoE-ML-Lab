Experimental vs theoretical probability
Law of Large Numbers: the experimental proportion (blue) approaches the true probability (green) as tosses increase. Basis of sampling, Monte Carlo and robot sensor averaging.
Notes: Probability
  • Theoretical probability = favourable outcomes ÷ all outcomes (heads = 0.5).
  • Experimental probability = observed frequency from trials.
  • More trials → smaller random error (about 1/√n).
  • Used in: Monte Carlo simulation, noise filtering, A/B testing, particle filters in robot localisation.
Experimental proportion of headsTrue probability
X-axis: number of tosses. Y-axis: proportion of heads (0 to 1). The blue line wiggles at first, then settles on the green line.
K-Means clustering (unsupervised)
Each step: (1) assign every point to its nearest centroid, (2) move each centroid to the mean of its points. Squares are centroids. Try a wrong k.
Notes: K-Means
  • Type: unsupervised learning (no labels).
  • Goal: split data into k groups by minimising within-cluster distance (inertia).
  • Steps: choose k → place centroids → assign points → recompute means → repeat until stable.
  • Choosing k: elbow method, silhouette score.
  • Pros: fast, simple. Cons: needs k, sensitive to start and outliers, assumes round clusters.
  • Used in: customer segmentation, image colour compression, grouping LiDAR points.
Data point (colour = its cluster)Square = centroid (cluster centre)
Press Step and watch the squares move to the middle of their colour group. Lower inertia means tighter clusters.
Random Forest (supervised)
Each tree learns on a bootstrap sample with random splits; the forest votes. Dots = training data, rings = test data. Try 1 tree, then 50: variance drops.
Notes: Random Forest
  • Type: supervised ensemble (classification or regression).
  • Many decision trees, each trained on a bootstrap sample with random feature choices; predictions are combined by voting (bagging).
  • Key parameters: n_estimators, max_depth, max_features, min_samples_leaf.
  • Pros: accurate, resists overfitting, gives feature importance. Cons: less interpretable, larger models.
  • Used in: fault detection, sensor classification, medical and credit-risk prediction.
  • Watch the gap between train and test accuracy to spot overfitting.
Class 0Class 1● = training data◯ = test data
Background colour = what the forest predicts there. Stronger colour = more trees agree. Rings in the wrong colour are test errors.
Support Vector Machine (linear)
The solid line is the decision boundary, dashed lines are the margin. Circled points are support vectors. Small C = wide margin, large C = fewer mistakes allowed.
Notes: SVM
  • Type: supervised classifier.
  • Finds the hyperplane with the maximum margin between classes; only support vectors define it.
  • Loss: hinge loss, max(0, 1 − y·f(x)). C trades margin width against training errors.
  • Kernels (RBF, polynomial) let SVMs separate non-linear data; this demo is the linear case.
  • Pros: strong on small, high-dimensional data. Cons: slow on very large data, needs feature scaling.
  • Used in: text classification, face and gesture recognition, bioinformatics.
Class 0Class 1— decision boundary- - margin◯ support vector
The line is placed to leave the widest empty street between the two classes. Only the circled points hold it in place.
Neural network (deep learning basics)
A 2-input, 1-hidden-layer network (tanh) with sigmoid output, trained by backpropagation and SGD. With 1 neuron it cannot solve XOR; with 4+ it can.
Notes: Neural Networks / Deep Learning
  • Neuron: output = activation(w·x + b). Layers of neurons learn features automatically.
  • Training: forward pass → loss (cross-entropy) → backpropagation → gradient descent update.
  • Hyperparameters: learning rate, hidden units, layers, epochs, batch size.
  • Deep learning = many layers: CNNs for images, RNNs/Transformers for sequences.
  • Risks: overfitting, needs lots of data; use validation sets, regularisation, early stopping.
  • Used in: vision for robots, speech, control policies, reinforcement learning.

Background colour = the network output (blue near 0, red near 1). Train more epochs and the coloured regions bend around the data.

from sklearn.datasets import make_blobs
X,_ = make_blobs(300, centers=3, random_state=0)
km = KMeans(n_clusters=3, n_init=10).fit(X)
print(km.labels_[:10], km.inertia_)
Random Forest
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
X,y = make_moons(300, noise=0.2)
Xtr,Xte,ytr,yte = train_test_split(X,y,test_size=0.3)
rf = RandomForestClassifier(n_estimators=50, max_depth=4).fit(Xtr,ytr)
print(rf.score(Xte,yte))

Neural network (PyTorch)
import torch, torch.nn as nn
net = nn.Sequential(nn.Linear(2,8), nn.Tanh(), nn.Linear(8,1), nn.Sigmoid())
opt = torch.optim.SGD(net.parameters(), lr=0.05)
X = torch.tensor(Xtr, dtype=torch.float32)
Y = torch.tensor(ytr, dtype=torch.float32).view(-1,1)
for epoch in range(200):
    loss = nn.BCELoss()(net(X), Y)
    opt.zero_grad(); loss.backward(); opt.step()

📝 Study notes (cheat sheet)

Types of ML

  • Supervised: learn from labelled data (SVM, Random Forest).
  • Unsupervised: find structure without labels (K-Means, PCA).
  • Reinforcement: learn by reward and penalty.

Evaluation metrics

Accuracy  = (TP+TN) / all
Precision = TP / (TP+FP)
Recall    = TP / (TP+FN)
F1 = 2PR / (P+R)
RMSE = sqrt(mean((y-ŷ)²))

Overfitting vs underfitting

  • Underfit: too simple, high error everywhere (high bias).
  • Overfit: memorises training data, poor test score (high variance).
  • Fix: more data, regularisation, simpler model, cross-validation.

Gradient descent

w ← w − η · ∂L/∂w
  • η = learning rate: too big diverges, too small is slow.
  • SGD uses one sample or a mini-batch per step.

Regression

Linear:   ŷ = w·x + b
Logistic: p = 1 / (1 + e^-(w·x+b))
  • Linear predicts numbers; logistic predicts class probability.

K-Nearest Neighbours

  • Classify a point by the majority of its k closest points.
  • Scale features first. Small k = noisy, large k = smooth.

PCA

  • Rotates data onto directions of largest variance.
  • Keep the top components to reduce dimensions and speed training.

Activation functions

sigmoid: 1/(1+e^-z)  (0 to 1)
tanh:    (-1 to 1)
ReLU:    max(0, z)
softmax: class probabilities

Robotics basics

  • Sensors: camera, LiDAR, IMU, encoders.
  • Actuators: motors, servos.
  • PID: u = Kp·e + Ki·∫e + Kd·de/dt
  • SLAM: build a map and locate the robot at once.

ML workflow

  • 1. Define the problem and collect data
  • 2. Clean and explore
  • 3. Split train / validation / test
  • 4. Train and tune
  • 5. Evaluate, deploy, monitor
