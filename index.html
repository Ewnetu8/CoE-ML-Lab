Experimental vs theoretical probability
Law of Large Numbers: the experimental proportion (blue) approaches the true probability (green) as tosses increase. Basis of sampling, Monte Carlo and robot sensor averaging.
Notes: Probability
  • Theoretical probability = favourable outcomes ÷ all outcomes (heads = 0.5).
  • Experimental probability = observed frequency from trials.
  • More trials → smaller random error (about 1/√n).
  • Used in: Monte Carlo simulation, noise filtering, A/B testing, particle filters in robot localisation.
Experimental proportion of headsTrue probability
X-axis: number of tosses. Y-axis: proportion of heads (0 to 1). The blue line wiggles at first, then settles on the green line.
K-Means clustering (unsupervised)
Each step: (1) assign every point to its nearest centroid, (2) move each centroid to the mean of its points. Squares are centroids. Try a wrong k.
Notes: K-Means
  • Type: unsupervised learning (no labels).
  • Goal: split data into k groups by minimising within-cluster distance (inertia).
  • Steps: choose k → place centroids → assign points → recompute means → repeat until stable.
  • Choosing k: elbow method, silhouette score.
  • Pros: fast, simple. Cons: needs k, sensitive to start and outliers, assumes round clusters.
  • Used in: customer segmentation, image colour compression, grouping LiDAR points.
Data point (colour = its cluster)Square = centroid (cluster centre)
Press Step and watch the squares move to the middle of their colour group. Lower inertia means tighter clusters.
Random Forest (supervised)
Each tree learns on a bootstrap sample with random splits; the forest votes. Dots = training data, rings = test data. Try 1 tree, then 50: variance drops.
Notes: Random Forest
  • Type: supervised ensemble (classification or regression).
  • Many decision trees, each trained on a bootstrap sample with random feature choices; predictions are combined by voting (bagging).
  • Key parameters: n_estimators, max_depth, max_features, min_samples_leaf.
  • Pros: accurate, resists overfitting, gives feature importance. Cons: less interpretable, larger models.
  • Used in: fault detection, sensor classification, medical and credit-risk prediction.
  • Watch the gap between train and test accuracy to spot overfitting.
Class 0Class 1● = training data◯ = test data
Background colour = what the forest predicts there. Stronger colour = more trees agree. Rings in the wrong colour are test errors.
Support Vector Machine (linear)
The solid line is the decision boundary, dashed lines are the margin. Circled points are support vectors. Small C = wide margin, large C = fewer mistakes allowed.
Notes: SVM
  • Type: supervised classifier.
  • Finds the hyperplane with the maximum margin between classes; only support vectors define it.
  • Loss: hinge loss, max(0, 1 − y·f(x)). C trades margin width against training errors.
  • Kernels (RBF, polynomial) let SVMs separate non-linear data; this demo is the linear case.
  • Pros: strong on small, high-dimensional data. Cons: slow on very large data, needs feature scaling.
  • Used in: text classification, face and gesture recognition, bioinformatics.
Class 0Class 1— decision boundary- - margin◯ support vector
The line is placed to leave the widest empty street between the two classes. Only the circled points hold it in place.
Neural network (deep learning basics)
A 2-input, 1-hidden-layer network (tanh) with sigmoid output, trained by backpropagation and SGD. With 1 neuron it cannot solve XOR; with 4+ it can.
Notes: Neural Networks / Deep Learning
  • Neuron: output = activation(w·x + b). Layers of neurons learn features automatically.
  • Training: forward pass → loss (cross-entropy) → backpropagation → gradient descent update.
  • Hyperparameters: learning rate, hidden units, layers, epochs, batch size.
  • Deep learning = many layers: CNNs for images, RNNs/Transformers for sequences.
  • Risks: overfitting, needs lots of data; use validation sets, regularisation, early stopping.
  • Used in: vision for robots, speech, control policies, reinforcement learning.

Study notes (cheat sheet)

Types of ML

  • Supervised: learn from labelled data (SVM, Random Forest).
  • Unsupervised: find structure without labels (K-Means, PCA).
  • Reinforcement: learn by reward and penalty.

Evaluation metrics

Accuracy  = (TP+TN) / all
Precision = TP / (TP+FP)
Recall    = TP / (TP+FN)
F1 = 2PR / (P+R)
RMSE = sqrt(mean((y-ŷ)²))

Overfitting vs underfitting

  • Underfit: too simple, high error everywhere (high bias).
  • Overfit: memorises training data, poor test score (high variance).
  • Fix: more data, regularisation, simpler model, cross-validation.

Gradient descent

w ← w − η · ∂L/∂w
  • η = learning rate: too big diverges, too small is slow.
  • SGD uses one sample or a mini-batch per step.

Regression

Linear:   ŷ = w·x + b
Logistic: p = 1 / (1 + e^-(w·x+b))
  • Linear predicts numbers; logistic predicts class probability.

K-Nearest Neighbours

  • Classify a point by the majority of its k closest points.
  • Scale features first. Small k = noisy, large k = smooth.

PCA

  • Rotates data onto directions of largest variance.
  • Keep the top components to reduce dimensions and speed training.

Activation functions

sigmoid: 1/(1+e^-z)  (0 to 1)
tanh:    (-1 to 1)
ReLU:    max(0, z)
softmax: class probabilities

Robotics basics

  • Sensors: camera, LiDAR, IMU, encoders.
  • Actuators: motors, servos.
  • PID: u = Kp·e + Ki·∫e + Kd·de/dt
  • SLAM: build a map and locate the robot at once.

ML workflow

  • 1. Define the problem and collect data
  • 2. Clean and explore
  • 3. Split train / validation / test
  • 4. Train and tune
  • 5. Evaluate, deploy, monitor

Chapter 1 · Artificial Intelligence Foundations

Definitions of AI

  • 1956 Dartmouth Conference: AI born as a field: the science and engineering of making intelligent machines (McCarthy, Minsky, Rochester, Shannon).
  • 1960s-1980s: symbolic reasoning and expert systems (e.g. MYCIN for medical diagnosis).
  • Modern: machine-oriented (tasks that need intelligence if done by humans) and task-oriented (perceive, reason, learn, decide). Focus on solving practical problems.

Probability in AI

Conditional:  P(A|B) = P(A∩B) / P(B)
Bayes:        P(A|B) = P(B|A)·P(A) / P(B)
Independence: P(A∩B) = P(A)·P(B)
Expectation:  E[X] = Σ x·P(X=x)
Variance:     Var(X) = E[(X − E[X])²]

Chapter 2 · Core Machine Learning Methods

Generative vs discriminative

Generative:     models P(X,Y); can create new data.   P(Y|X) ∝ P(Y)·Π P(xi|Y)   (Naive Bayes)
Discriminative: models P(Y|X) directly.               P(Y=1|X) = 1 / (1 + e^-(wᵀX+b))  (Logistic Regression)

Perceptron and MLP

Perceptron: y = 1 if wᵀX + b > 0 else 0
Update:     w ← w + η(y_true − y_pred)·X ,  b ← b + η(y_true − y_pred)
MLP:        a(l) = f(W(l)·a(l−1) + b(l))
Backprop:   W(l) ← W(l) − η ∂L/∂W(l)

SVM and kernels

Hard margin: min ½||w||²  s.t. yi(wᵀxi + b) ≥ 1
Soft margin: min ½||w||² + C Σ ξi  s.t. yi(wᵀxi + b) ≥ 1 − ξi, ξi ≥ 0
Linear: K = xᵀx'     Polynomial: K = (xᵀx' + c)^d     RBF: K = exp(−||x−x'||² / 2σ²)

Active learning

Uncertainty sampling: x* = argmax_x ( 1 − max_y Pθ(y|x) )

Chapter 3 · Deep Learning Architectures (CNN, SGD, BatchNorm)

CNN building blocks

Convolution:  Y(i,j) = Σm Σn X(i+m, j+n)·K(m,n)
Output size:  floor((N − K + 2P) / S) + 1
ReLU:         f(x) = max(0, x)
Max pooling:  Y(i,j) = max X(i+m, j+n)
Pipeline:     Input → Convolution → ReLU → Pooling → Fully connected → Output

Optimisation

Types: Batch GD (all data) · SGD (one sample) · Mini-batch GD (small batch)
SGD:       θ(t+1) = θ(t) − η ∇θ L(xi, yi)
Momentum:  v(t) = γ v(t−1) + η ∇L ,  θ(t+1) = θ(t) − v(t)

Batch normalisation

μ = (1/m) Σ xi     σ² = (1/m) Σ (xi − μ)²
x̂i = (xi − μ) / sqrt(σ² + ε)     yi = γ·x̂i + β

import torch, torch.nn as nn, torch.optim as optim
from torchvision import datasets, transforms
import matplotlib.pyplot as plt

tf = transforms.Compose([transforms.ToTensor(), transforms.Normalize((0.5,), (0.5,))])
train_loader = torch.utils.data.DataLoader(
    datasets.MNIST('./data', train=True, download=True, transform=tf), batch_size=64, shuffle=True)

class SimpleCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(1, 32, 3); self.bn1 = nn.BatchNorm2d(32)
        self.relu = nn.ReLU(); self.pool = nn.MaxPool2d(2)
        self.fc1 = nn.Linear(32*13*13, 10)
    def forward(self, x):
        x = self.pool(self.relu(self.bn1(self.conv1(x))))
        return self.fc1(x.view(x.size(0), -1))

model = SimpleCNN(); criterion = nn.CrossEntropyLoss()
optimizer = optim.SGD(model.parameters(), lr=0.01)
losses = []
for epoch in range(5):
    run = 0.0
    for data, target in train_loader:
        optimizer.zero_grad(); loss = criterion(model(data), target)
        loss.backward(); optimizer.step(); run += loss.item()
    losses.append(run); print(f'Epoch {epoch+1}: Loss={run:.4f}')
plt.plot(losses); plt.xlabel('Epoch'); plt.ylabel('Loss'); plt.title('Training Loss Curve'); plt.show()

Chapter 4 · Advanced Generative Models (GAN, VAE, Flow, SSL)

GAN

min_G max_D V(D,G) = E_x~pdata[ log D(x) ] + E_z~pz[ log(1 − D(G(z))) ]
Train: (1) update D to tell real from fake, (2) update G to fool D.
Variants: DCGAN (conv), cGAN (class-conditioned), WGAN (Wasserstein, more stable)

Autoencoders and VAE

AE:   z = fθ(x), x̂ = gφ(z),  L = ||x − x̂||²
VAE:  z ~ N(μ(x), σ²(x)),  z = μ + σ⊙ε, ε ~ N(0,1)
ELBO: L = −E_q[ log pθ(x|z) ] + KL( qφ(z|x) || p(z) )
KL:   ½ Σj ( μj² + σj² − log σj² − 1 )

Flow-based models and SSL

Flow:    x = fθ(z),  pX(x) = pZ(z) · | det ∂fθ⁻¹(x)/∂x |   (PixelCNN, WaveNet are sequential models)
InfoNCE: L = −log [ exp(sim(hi,hj)/τ) / Σk exp(sim(hi,hk)/τ) ]
SSL ideas: contrastive learning, masked prediction (BERT, MAE), pretext tasks (rotation, jigsaw)

VAEProbabilisticELBO (recon + KL)Smooth latent space

Chapter 5 · Sequential Models (RNN, LSTM, GRU)

RNN

ht = φ(Wxh·xt + Whh·h(t−1) + bh),   yt = Why·ht + by
Problems: vanishing gradient (hard to learn long dependencies), exploding gradient (unstable)

LSTM

ft = σ(Wf xt + Uf h(t−1) + bf)      forget gate
it = σ(Wi xt + Ui h(t−1) + bi)      input gate
C̃t = tanh(Wc xt + Uc h(t−1) + bc)   candidate
Ct = ft ⊙ C(t−1) + it ⊙ C̃t          cell state
ot = σ(Wo xt + Uo h(t−1) + bo)      output gate
ht = ot ⊙ tanh(Ct)

GRU

zt = σ(Wz xt + Uz h(t−1) + bz)          update gate
rt = σ(Wr xt + Ur h(t−1) + br)          reset gate
h̃t = tanh(Wh xt + Uh (rt ⊙ h(t−1)) + bh)
ht = (1 − zt) ⊙ h(t−1) + zt ⊙ h̃t

    for i in range(len(d) - n):
        X.append(d[i:i+n]); y.append(d[i+n])
    return np.array(X), np.array(y)

SEQ = 30
X, y = create_sequences(t, SEQ)
k = int(0.8 * len(X)); Xtr, Xte, ytr, yte = X[:k], X[k:], y[:k], y[k:]

def run(layer):                      # layer = SimpleRNN, LSTM or GRU
    m = Sequential([Input((SEQ, 1)), layer(50, activation='tanh'), Dense(1)])
    m.compile(optimizer='adam', loss='mse')
    h = m.fit(Xtr, ytr, epochs=50, batch_size=32, validation_split=0.1, verbose=0)
    mse = np.mean((m.predict(Xte) - yte) ** 2)
    print(layer.__name__, 'test MSE:', mse); return h

for L in (SimpleRNN, LSTM, GRU):
    h = run(L); plt.plot(h.history['val_loss'], label=L.__name__)
plt.legend(); plt.xlabel('Epoch'); plt.ylabel('Validation loss'); plt.show()

Chapter 6 · Learning Theory and Challenges

Learning paradigm

Data S = {(xi, yi)} ~ D     Hypothesis space H = {h : X → Y}
True risk:      R(h) = E[ ℓ(h(x), y) ]
Empirical risk: R̂(h) = (1/n) Σ ℓ(h(xi), yi)
ERM:            ĥ = argmin_h R̂(h)

Bias-variance, over/underfitting

E[(y − f̂(x))²] = Bias² + Variance + σ²
High bias → underfitting     High variance → overfitting (R̂ ≪ R)
Generalisation gap = |R(h) − R̂(h)|

Regularisation and VC dimension

Ridge (L2): Cost = (1/n) Σ (yi − ŷi)² + λ Σ wi²
Lasso (L1): Cost = (1/n) Σ (yi − ŷi)² + λ Σ |wi|     (encourages sparsity)
VC(H) = max n such that H can shatter n points
R(h) ≤ R̂(h) + sqrt( VC(H)·log n / n )

Chapter 1 · Advanced Regression Models

Regression revision

Simple:   y = β0 + β1·x + ε
Multiple: y = β0 + β1·x1 + β2·x2 + … + βp·xp + ε
  • Assumptions: linearity, independence of errors, homoscedasticity (constant error variance), normally distributed errors.

Evaluating regression

MAE  = (1/n) Σ |y − ŷ|
MSE  = (1/n) Σ (y − ŷ)²          RMSE = sqrt(MSE)
R²   = 1 − SS_res / SS_tot
  • Split the data (e.g. 80% / 20%), use cross-validation, and always inspect residual plots.
  • Bias-variance: high bias = underfitting, high variance = overfitting; Error = Bias² + Variance + noise.

Chapter 3 · Ensembles and Neural Networks

Ensembles

  • Bagging: train models on bootstrap samples and average them (Random Forest).
  • Boosting: models trained in sequence, each fixing the previous errors (AdaBoost, Gradient Boosting).
  • Voting / stacking: combine different model types (hard or soft voting).

Neural networks

Forward:   a(l) = f(W(l)·a(l−1) + b(l))
Backprop:  W(l) ← W(l) − η ∂L/∂W(l)
Activations: sigmoid 1/(1+e^-z) · tanh · ReLU max(0,z) · softmax
Key parameters: hidden layers and units, activation, learning rate, solver (SGD / Adam), epochs, batch size

Chapter 5 · Convolutional Neural Networks

CNNs

Convolution:  Y(i,j) = Σ X(i+m, j+n)·K(m,n)
Pipeline:     Conv → ReLU → Pooling (stack many) → Flatten → Dense → Softmax (multi-class)
ResNet:       y = F(x) + x   (skip connections make very deep networks trainable)
  • Object detection: predict class and bounding box (e.g. YOLO).

Chapter 6 · Recurrent Neural Networks

Recurrent networks

Elman RNN:  ht = tanh(Wxh·xt + Whh·h(t−1) + b)
Training:   back-propagation through time (BPTT)
LSTM / GRU: gated units that keep long-term information
Vanishing gradient: gradients shrink over long sequences → fix with LSTM/GRU, gradient clipping

Chapter 8 · Active Learning, Transfer Learning and Applications

Active learning

  • Train on a small labelled set, query the most informative samples, label them, retrain, repeat.
  • Pool-based vs stream-based settings; sampling by uncertainty, committee disagreement or diversity.

Transfer learning

  • Reuse a model trained on a large task. Feature extraction: freeze the base. Fine-tuning: update some or all layers.
  • Related ideas: multi-task learning, zero-shot learning.

Applications

  • Computer vision: classification, detection, face recognition.
  • NLP: sentiment analysis, machine translation, question answering, summarisation.
