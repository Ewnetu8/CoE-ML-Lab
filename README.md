# AI & Robotics Center of Excellence - ML Lab

Files
- index.html - the interactive lab (open in a browser, or deploy it)
- python/ml_examples.py - Python versions of the same algorithms

Logins (change them!): admin / Coe@Admin2026  and  student / Coe@Learn2026
Passwords are stored as SHA-256 hashes of "coe|username|password" in the `U={...}` line of index.html.
The login only hides the page; it is NOT real security.

Deploy on GitHub Pages
1. Create a public repository on github.com.
2. Upload index.html (and the python folder).
3. Settings -> Pages -> Deploy from branch -> main -> / (root) -> Save.
4. Open https://YOUR-USERNAME.github.io/REPO-NAME/

Deploy on Netlify
Drag the coe-ml-lab folder onto app.netlify.com/drop.
